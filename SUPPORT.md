# Support

SmartCities is currently pre-alpha.

Use GitHub issues for reproducible class-library, documentation, CI, website, localization, interoperability, and future product defects that are safe to discuss publicly.

Do not use public issues for weaponizable security details, citizen personal information, confidential municipal/customer information, secrets, credentials, or sensitive Code of Conduct reports.

See [SECURITY.md](SECURITY.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

There is currently no production support SLA, municipal procurement guarantee, safety certification, or professional-service commitment.
