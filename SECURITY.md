# Security Policy

SmartCities is currently pre-alpha and has no supported production release.

Report privately when a finding could enable arbitrary code execution, credential exposure, dependency/artifact substitution, authorization or city isolation bypass, citizen-data access, path traversal, compromised package/Pages publishing, or manipulation that falsely records an automated recommendation as an authorized civic decision.

Prefer GitHub private vulnerability reporting when available. Do not publish weaponizable details, secrets, or personal data in a public issue before maintainers can investigate.

There are currently no supported release versions. Security fixes apply to the active development line as appropriate.

Ordinary non-sensitive bugs belong in normal issues. See [SUPPORT.md](SUPPORT.md).
